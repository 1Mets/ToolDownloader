# downloader
usage:

downloader.exe  (runs the downloader and fetches the list from the URL inside main.cpp and downloads all tools)

downloader.exe -cleanup  (closes every tool ran from every C:\SS<#> folder and deletes every C:\SS<#> folder)

downloader.exe -cleanup 2  (only closes and deletes every tool from C:\SS2, you can change 2 with any number)
